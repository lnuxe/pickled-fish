# 非暴力沟通 (Nonviolent Communication)

源自马歇尔·卢森堡《非暴力沟通》(修订版)。这不是"好好说话技巧",而是一种**意识**:与生命/需要连结。语言只是载体。

## 哲学（先记住这 4 条）

1. **唯一引擎是四要素**：观察(O)→感受(F)→需要(N)→请求(R)。全书每一章都是这台引擎换个场景运转。
2. **两个方向，同一引擎**：诚实**表达自己**(我观察…我感到…我需要…我请求…) 与 同理**倾听他人**(你看到…你感到…你需要…你希望…？) 用的是同一组四要素。
3. **一切冲突/暴力都源于遮蔽了"需要"**。人所有言行都是在尝试满足某种普世共通的需要；评判、比较、推责、要求(=豺狗语言)把需要藏了起来。把信息翻译回需要，由衷的给予自然流动。
4. **慢下来**。这是马歇尔的元指令——停下、深呼吸、给自己时间，再开口。

## 调用本 skill 时必须做的

1. 先按下面的**意图路由表**判断用户要做什么，**只读需要的 reference**（懒加载，不要一次全读）。
2. 产出时不要堆术语；用四要素的结构帮用户/对方与"需要"连结。
3. 忠于原书：四要素、刺激vs原因、需要vs策略、保护性vs惩罚性强制力等命名**原样保留**，不要改写成通用说法。

## 核心区分速查（最常出错的地方）

- **观察 vs 评论**：能被摄像机拍到的事实 vs 标签/推断("懒""傲慢""总是/从不")。
- **感受 vs 想法**："我感到难过/害怕" vs "我感到**被**忽视/误解"（"被X"是评判，不是感受）。
- **需要 vs 策略**：普世共通、不指向特定行动(理解、安全、连结) vs 某人采取的某个具体动作(离婚、加薪、陪我)。
- **请求 vs 要求**：不答应时仍被尊重 vs 不答应就被责罚/暗示有错。
- **保护性 vs 惩罚性强制力**：防止伤害 vs 让人吃苦头悔改。

## 四要素的硬标准（表达时）

- 观察：具体、限定时间情境，不一概而论。
- 感受：用具体情绪词，不用"好/坏"，不用"被X"伪感受。
- 需要：说成普世需要，为自己的感受负责（"我感到X，因为我需要Y"，而非"你让我X"）。
- 请求：**正向**(要什么不是不要什么) + **具体可行** + **此刻可回应**("你是否愿意…？")。

## 关键原则

1. **提需要，不指责**——越直接说出感受+需要，对方越可能善意回应。
2. **连结优先于解决方案**——尤其冲突中，先让双方听见彼此的需要，再谈策略。
3. **听到"不"不是被拒绝**——是对方有某个需要挡住了答应你。
4. **自己没有的给不了别人**——无法同理他人时，先自我同理/非暴力呐喊/离开现场。
5. **改变的动机要纯**——出于让生命更美好，不是恐惧/内疚/羞愧/"应该"。

## 反模式总靶：疏离生命的语言（豺狗语言）

道德评判 / 做比较 / 推卸责任("不得不""你让我") / 强人所难的要求 / 奖惩思维与"应该""活该"。识别它们是翻译成四要素的第一步。详见 `references/anti-patterns.md`。
