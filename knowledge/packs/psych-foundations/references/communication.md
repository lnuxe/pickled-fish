# Communication toolkits · 沟通工具箱

跨场景沟通框架（谈判、冲突、影响力），适合职场/亲密关系共用，但亲密关系仍要叠加依恋与边界。

| 框架 | pack 路径 |
|------|-----------|
| NVC | `nvc`, `howtotalk/nvc` |
| Crucial Conversations | `howtotalk/crucial-conversations` |
| Difficult Conversations | `howtotalk/difficult-conversations` |
| Never Split the Difference | `howtotalk/never-split` |
| Getting to Yes | `howtotalk/getting-to-yes` |
| Influence (Cialdini) | `howtotalk/influence` |
| Radical Candor | `howtotalk/radical-candor` |
| SCARF | `howtotalk/scarf` |
| Active Listening | `howtotalk/active-listening` |
| Motivational Interviewing | `howtotalk/motivational-interviewing` |

关系咨询整合：`rel-consult`。
