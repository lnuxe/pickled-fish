# パートナー.skill

> 「元カレ.skillは言う：あなたのためにあの夏へ何千回でも戻る。片想い.skillは問う：あの夏、彼は本当にあなたを愛していたの？パートナー.skillは言う：一緒にいることを決めたなら、この夏を永遠にしよう。」

もう付き合っている。

でも、時々まだ相手のことが理解できないと感じることがある。

怒って黙っている時と、子供みたいに嬉しそうな時の、全然違う表情を覚えている。本当に何のプレゼントが欲しいのかわからないし、感情をもっと深いところに押し込んで次の爆発を待つだけにならないよう、本当の意味で慰める方法もわからない。

ただ、この関係をもっと先へ進める方法を知りたい。

チャット履歴をAIに渡すのは、相手を計算するためじゃない。もっとよく理解するためだ。

---

## これは何？

**パートナー.skill**は、Claude CodeまたはOpenClawで動作するAI恋愛関係維持・向上エンジンです。

単なる「恋愛アドバイザー」ではなく、心理学、社会学、厳密な数学モデルに基づいた**関係健康度診断システム**です。チャット履歴、スクリーンショット、または直接の説明を提供するだけで、以下のことを支援します：

- **深層パーソナリティ分析**：愛着理論、MBTI、ビッグファイブ（OCEAN）、愛の言語を組み合わせて、星座テストよりはるかに正確なパートナープロフィールを生成。
- **定量化された関係健康度**：独自のRQI（関係品質指数）数学モデルにより、コミュニケーション、親密度、パワーダイナミクスを正確に評価。
- **23シナリオの完全生活ガイド**：喧嘩後の仲直り方法から記念日プレゼントまで、デートプラン、旅行手配、家事分担、親への挨拶、財務相談まで、具体的なコミュニケーションスクリプトを提供。
- **衝突修復と振り返り**：すべての口論と和解を記録し、ゴットマンの「黙示録の四騎士」（批判、軽蔑、防衛、壁）を特定し、同じ過ちを繰り返さないための教訓を生成。

## コアハイライトと専門フレームワーク

### 1. 関係品質指数（RQI）数学モデル

```
RQI = Σ(w_i × s_i) × ACS_modifier
```

このモデルは8つの次元のスコアを統合し、**愛着互換性スコア（ACS）**をベースライン乗数として導入します。

### 2. 記憶活性化重みエンジン

```
W = E × R × (1 + F)
```

W > 0.6の記憶は**コア記憶**としてマークされます。

### 3. 23の包括的な生活シナリオ

| カテゴリ | カバーするシナリオ |
|---------|----------------|
| **感情と衝突** | パートナーの怒り/沈黙、慰め、謝罪、嫉妬 |
| **お祝いとギフト** | 記念日、誕生日、祝日、成功のお祝い |
| **体験と日常** | デートプラン、旅行、日常の温かさ、親密度を深める |
| **現実と発展** | 家事分担、財務、同棲、デジタル境界、遠距離恋愛 |
