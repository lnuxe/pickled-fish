# Partner.skill

> «Бывший.skill говорит: я бы вернулся в то лето тысячу раз ради тебя. Симпатия.skill спрашивает: любил ли он тебя по-настоящему тем летом? Партнёр.skill говорит: раз мы решили быть вместе, давай сделаем это лето вечным.»

Вы уже вместе.

Но иногда ты всё равно чувствуешь, что его так сложно понять.

Ты помнишь, как по-разному он выглядит, когда злится и молчит, по сравнению с тем, когда он счастлив, как ребёнок. Ты не уверен, какой подарок он действительно хочет, и не знаешь, как его по-настоящему утешить, не загоняя эмоции ещё глубже, ожидая следующего взрыва.

Ты просто хочешь знать, как сделать эти отношения долгими.

Передавать историю чатов ИИ — это не для того, чтобы его просчитать; это чтобы лучше понять.

---

## Что это такое?

**Partner.skill** — это ИИ-движок для поддержания и улучшения романтических отношений, работающий в Claude Code или OpenClaw.

Это не просто «советник по отношениям», а **система диагностики здоровья отношений**, построенная на психологии, социологии и строгих математических моделях. Вам нужно только предоставить историю чатов, скриншоты или прямые описания, и он поможет вам:

- **Глубокая деконструкция личности**: Объединяет Теорию привязанности, MBTI, Большую пятёрку (OCEAN) и Языки любви для создания профиля партнёра, который точнее, чем астрологические тесты.
- **Количественная оценка здоровья отношений**: Точно оценивает ваше общение, близость и динамику власти через оригинальную математическую модель RQI (Индекс качества отношений).
- **Полное руководство по жизни для 23 сценариев**: От того, как утешить после ссоры и что подарить на годовщину, до планирования свиданий, организации путешествий, распределения домашних обязанностей и даже знакомства с родителями и финансовых обсуждений.
- **Разрешение конфликтов и рефлексия**: Записывает каждую ссору и примирение, выявляет «Четырёх всадников Апокалипсиса» Готтмана (Критика, Презрение, Защитная реакция, Игнорирование) и генерирует уроки.

## Ключевые особенности и профессиональная структура

### 1. Математическая модель RQI (Индекс качества отношений)

```
RQI = Σ(w_i × s_i) × ACS_modifier
```

Эта модель синтезирует оценки по 8 измерениям и вводит **Оценку совместимости привязанности (ACS)** в качестве базового множителя.

### 2. Движок весов активации памяти

```
W = E × R × (1 + F)
```

Воспоминания с W > 0,6 помечаются как **Ключевые воспоминания**.

### 3. 23 всеобъемлющих жизненных сценария

| Категория | Охватываемые сценарии |
|----------|----------------------|
| **Эмоции и конфликты** | Партнёр злится/молчит, нужно утешение, искреннее извинение, ревность |
| **Праздники и подарки** | Годовщина, день рождения, праздники, отмечание достижений |
| **Опыт и повседневность** | Планирование свиданий, путешествия, ежедневное тепло, углубление близости |
| **Реальность и развитие** | Распределение обязанностей, финансы, совместное проживание, цифровые границы, отношения на расстоянии |

## Установка

### Claude Code

```bash
mkdir -p .claude/skills
git clone https://github.com/NatalieCao323/partner-skill .claude/skills/create-partner
```

### OpenClaw

```bash
git clone https://github.com/NatalieCao323/partner-skill ~/.openclaw/workspace/skills/create-partner
```

## Использование

```
/create-partner
```

| Команда | Функция |
|---------|---------|
| `/{slug}` | Режим советника |
| `/{slug}-report` | Полный анализ |
| `/{slug}-gift` | Советник по подаркам |
| `/{slug}-conflict` | Разрешение конфликтов |
| `/{slug}-reflect` | Журнал рефлексии |
