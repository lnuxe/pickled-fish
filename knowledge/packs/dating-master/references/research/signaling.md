# 信号博弈层：约会中的信号质量评估

---

## 1. Costly Signal vs Cheap Talk

信号理论（Spence, 1973; Zahavi, 1975）的核心命题：**只有付出真实成本的信号才可信**。

### 基本框架

| 类型 | 定义 | 特征 | 可信度 |
|------|------|------|--------|
| **Costly signal**（高成本信号） | 发出信号需要付出真实的时间/金钱/机会成本 | 难以伪造 | 高 |
| **Cheap talk**（廉价信号） | 说一句话不需要任何成本 | 任何人都能说 | 低 |

### 约会场景中的信号分类

**Costly signals（可信度高）：**

| 行为 | 付出的成本 | 为什么可信 |
|------|----------|----------|
| 凌晨开车来接你 | 时间 + 睡眠 + 油费 | 不喜欢的人不会这么做 |
| 记住你随口说过的事并行动（你说想吃草莓，ta 买了） | 注意力 + 行动力 | 需要真正在意才会记住 |
| 在朋友面前提到你 / 介绍你给朋友 | 社会资本 | 愿意把你放进 ta 的社交圈 = 认真 |
| 为你调整计划（推掉聚会陪你） | 机会成本 | 你的优先级 > 其他事 |
| 生病时来照顾你 | 时间 + 精力 + 传染风险 | 纯粹利他行为 |
| 讨论未来计划时自然包含你 | 心理承诺 | 把你纳入长期规划 |

**Cheap talk（可信度低）：**

| 表达 | 成本 | 为什么不可信 |
|------|------|------------|
| "我好想你" | 0 | 打五个字不需要任何付出 |
| "下次带你去xxx" | 0 | 没有具体时间 = 大概率不会兑现 |
| "你是我见过最好的人" | 0 | 过度赞美是最廉价的信号 |
| "等我忙完就来找你" | 0 | "忙完"没有截止日期 |
| "我对你是认真的" | 0 | 需要说出来的"认真"通常不太认真 |
| 深夜发"在吗" | 极低 | 可能是无聊/寂寞的群发 |

### 关键判断规则

1. **言行一致性检验**：嘴上说"想见你"，但从不主动约 → cheap talk
2. **成本检验**：这个行为如果 ta 不喜欢你，ta 会做吗？→ 不会 = costly signal
3. **替代性检验**：这个行为 ta 对所有人都这样吗？→ 是 = 不是对你的特殊信号

## 2. 投入不对称识别

投入不对称是关系动态中最重要的诊断指标。

### 三个核心比值

| 维度 | 测量方法 | 健康范围 | 警告信号 |
|------|---------|---------|---------|
| **消息长度比** | 你的平均消息长度 / ta的平均消息长度 | 0.7-1.5 | >2.0（你写太多）或 <0.5（ta写太多） |
| **发起频率比** | 你主动发起聊天次数 / ta主动发起次数 | 0.5-2.0 | >3.0（你总是先找ta）|
| **时间成本比** | 你为ta投入的时间 / ta为你投入的时间 | 大致对等 | 明显一方投入远超另一方 |

### 投入不对称的聊天特征

**你投入过多的信号：**
- 你的消息比 ta 长 3 倍以上
- 你总是先发消息
- 你问 3 个问题，ta 只回答 1 个
- 你分享日常，ta 不分享
- 你秒回，ta 隔几个小时

**ta 投入过多的信号：**
- ta 连续发多条消息
- ta 主动找话题怕冷场
- ta 你不回就追问
- ta 对你的简短回复做长篇回应

### 投入不对称的动态演化

```
初期不对称 → 追的一方加大投入 → 逃的一方更加退缩
    → 追的一方焦虑升级 → 逃的一方感到压力
    → 最终破裂或追的一方放弃
```

**打破不对称的唯一方法**：追的一方减少投入，观察对方是否主动补回。如果对方不补 → 就是不够喜欢。

## 3. 可信承诺 vs 口头承诺

### 判断框架

| 维度 | 可信承诺 | 口头承诺 |
|------|---------|---------|
| **具体性** | "这周六下午三点我来接你" | "下次带你去" |
| **时间锚点** | 有明确日期/时间 | "有空""改天""到时候" |
| **行动支撑** | 说完后有后续行动（订餐厅、买票） | 说完就没有了 |
| **主动跟进** | 到了时间主动确认 | 需要你提醒才想起 |
| **一致性** | 历史承诺兑现率高 | 经常"放鸽子"或模糊取消 |

### 承诺可信度评分标准

| 评分 | 特征 |
|------|------|
| 9-10 | 有具体时间+地点+主动跟进+历史兑现率高 |
| 7-8 | 有具体时间但需要你推进细节 |
| 5-6 | 有意愿但没有具体计划 |
| 3-4 | 模糊承诺（"下次""改天"）+没有后续 |
| 1-2 | 反复承诺反复不兑现 |
