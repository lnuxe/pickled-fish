## 效果示例

```
用户      ❯ 我约她周末出来她说"最近有点忙 下周看看吧"

情场高手  ❯ 你听我说——我见过太多这样的了。

            "最近有点忙，下周看看"，这句话翻译过来就是：
            我对你没有那么期待。

            真正想见你的人不会说"看看"，会说"这周不行，
            周三可以吗？"——有替代方案才是真忙。
            没有替代方案的"忙"，就是一张永不兑现的支票。

            📊 信号强度：3/10

            你现在有两条路——
            第一条：不追了，等她。真喜欢你的人不会让你猜。
            第二条：过几天发一条具体邀约（"周三晚上吃饭？"），
            她的回应就是最终答案。再模糊一次，你就该放手了。

            我给你说句难听的：追得越紧，逃得越快。
            这不是你不够好，是她没有那么想见你。
```

```
用户      ❯ 我发了三段话分享今天的事，他回了"哈哈 是吗"，
            然后我又发一段，他回"嗯嗯"。每次都是我先找他。

情场高手  ❯ 你的问题不在于他回复短，在于你从一开始就没建立对等关系。

            你们现在就像两个人拔河，但只有你一个人在用力。
            你写了几百字，他回了不到十个字。
            这不叫聊天，这叫你在自言自语。

            ⚖️ 投入比：你 9 : 他 1
            📊 信号强度：2/10

            我见过很多像你这样的情况。你以为再发一条有趣的，
            他就会多回一点。但核心问题不是你的内容不够好，
            是他的投入不够。你没办法靠发消息让一个人喜欢你。

            但是，这不是没有解的——
            停下来。不找他，不发动态@他，就是停。等3-5天。
            如果他来找你，说明还有戏。如果他不来——
            你心里其实已经有答案了，只是不愿意承认。
```

```
用户      ❯ 她说"你人挺好的" 这是什么意思

情场高手  ❯ 这句话我太熟悉了，它有两个完全相反的意思。

            如果你刚表白过——这是好人牌。
            翻译："你很好，但我对你没感觉。"
            "但是"马上就要来了。

            如果是她日常聊天中主动说的——
            可能是真心夸赞，甚至是在试探你。
            关键看她说完之后做了什么：
            继续聊 = 有兴趣。结束对话 = 客气。

            ⚠️ 信息不够，你再给我说两个细节：
            前后文是什么？你有没有暗示过喜欢她？

            我给你说句难听的：
            如果你需要一个导师来帮你分析三个字，
            答案通常不是你想听的那个。
            真正喜欢你的人，不会让你猜。
```

## 安装

### 方式一：一键安装（推荐）

<details>
<summary><strong>前置条件：安装 Node.js（已有的跳过）</strong></summary>

1. 打开 [nodejs.org](https://nodejs.org/)，下载 **LTS 版本**
2. 双击安装包，一路点「下一步」即可
3. 安装完成后打开终端（Windows 用 PowerShell，Mac 用 Terminal），验证：

```bash
node --version
```

显示 `v18.x.x` 或更高版本号就行。

</details>

然后在终端运行：

```bash
npx skills add YixiaJack/dating-master-skill
```

看到 `✔ Skill installed` 就成功了。装完后在你常用的 AI 编程工具里直接触发即可。

### 方式二：手动安装（不想用命令行的看这里）

1. 去 [GitHub 仓库](https://github.com/YixiaJack/dating-master-skill) 下载 `SKILL.md` 文件
2. 放到你项目的 skills 目录中（例如 `.claude/skills/`、`.cursor/skills/` 等，取决于你用的工具）

就这么简单，不需要任何命令。

## 它蒸馏了什么

这个 Skill 不是拍脑袋写的。它的分析框架来自四个学术领域：

| 理论来源 | 关键人物 | 在本 Skill 中的作用 |
|---------|---------|-------------------|
| **语用学** | H.P. Grice / J. Searle | 分析约会对话中模糊语、间接言语行为和"话中话" |
| **依恋理论** | J. Bowlby / M. Ainsworth | 识别聊天行为中的依恋风格和追-逃动态 |
| **关系动力学** | J. Gottman | 诊断 pursue-withdraw pattern 和投入不对称 |
| **信号博弈论** | M. Spence / A. Zahavi | 区分 costly signal 和 cheap talk，评估信号可信度 |

### 四层分析框架

| 分析层 | 回答的问题 |
|--------|----------|
| **语义还原** | 这句话的字面意思 vs 真实意图是什么？ |
| **关系动态诊断** | 谁在追、谁在逃、投入是否对称？ |
| **信号质量评估** | 对方的信号是真的（costly）还是空话（cheap）？ |
| **策略建议** | 你有哪些选项？每个选项的效果和风险是什么？ |

## 诚实边界

**能做的：**
- 基于语用学分析聊天潜台词
- 识别投入不对称和追-逃动态
- 区分 costly signal 和 cheap talk
- 给出有理论支撑的回应策略建议
- 涉及 PUA 操控或情感虐待信号时直接警告

**做不到的：**

| 维度 | 说明 |
|------|------|
| 单条消息分析 | 置信度低，会主动要求更多上下文 |
| 人格诊断 | 只做行为模式观察，不是心理测试 |
| 替你做决定 | 给框架和信息，你自己判断 |
| 读心术 | 任何分析都是推断，不是事实 |

**一个不告诉你局限在哪的导师，不值得信任。**

## 它不是什么

| 它不是 | 为什么不是 |
|--------|----------|
| **PUA 工具** | 不教操控。帮你看穿，不帮你套路别人 |
| **心理咨询替代品** | 涉及严重心理问题请找专业人士 |
| **算命** | 不预测未来，洞察当前 |
| **恋爱鸡汤** | "你值得被爱"不是分析，是废话 |
| **那种收你几万块的骗子导师** | 这个免费、开源、不卖课 |
